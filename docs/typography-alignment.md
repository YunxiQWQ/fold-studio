# 字体与对齐面板

选中文字、文字分段或包含文字的组合，右侧显示“字体与文字排版”。多选时，字体操作只作用于选区内未锁定的文字，混合属性显示为空或“混合”。在图层树中选中一个 `tspan`，可以只修改该分段，连续操作仍保持该分段选中。

- 点击字体右侧的 ▾ 打开下拉框，在搜索框按名称筛选，点击某一行即可应用；每行按对应字体显示名称。支持方向键、回车选择与 Esc 取消，字体较多时滚动继续载入。字体名称输入框仍可直接填写 CSS 字体／后备列表。
- 支持的浏览器在下拉框中显示“读取本机字体”。只有点击后才请求浏览器授权；成功后按名称列出本机已安装字体并去重。字体列表仅保留在当前页面内存中，刷新后重新读取。拒绝授权或不支持此 API 时，常用列表和手动名称仍可使用。应用不上传或嵌入字体文件；换电脑后需要安装同名字体。
- 字号支持 pt 和 mm，1 pt = 25.4 / 72 mm。字号与字距按当前 SVG 变换换算，批量操作会分别补偿不同父组的缩放，保留对象原有变换。零缩放下相关物理尺寸控件停用，可先在高级属性中修正变换。
- 字重 100–900、粗体、斜体、下划线和删除线可直接操作；装饰开关独立。`Ctrl / Command + B / I / U` 与面板共用操作逻辑。
- 字距和词距按毫米输入。多行文字可调整行距倍数、左／中／右对齐与横／竖排；段落对齐保留整体左边界。文字内容框和画布双击输入保留换行，新增行沿用当前行距。整段重写内容按首个分段样式重排；仅改字体、字号、字重等不会扁平化原分段。
- 复杂路径文字继续保留 `textPath` 与高级 SVG 属性。路径排版本身由原路径和起始偏移控制，不将其重排成普通段落。

选中一个或多个对象，右侧同时显示“对齐与分布”：

| 对齐参照 | 行为 |
| --- | --- |
| 自动 | 单选对齐当前包装面板，多选对齐整个选区 |
| 所选对象边界 | 使用选区的整体外接边界，至少两个对象 |
| 关键对象 | 最后选中的对象保持不动，其余对象向它对齐 |
| 当前包装面板 | 使用右侧面板下拉框选定的包装面；内面按阅读方向映射 |
| 整张刀版 | 使用完整刀版的外接范围 |

提供左、中、右、上、中、下六种对齐。分布可选择“中心等分”或“间距相等”；自动分布至少三个对象。选择“间距相等”并输入 0–1000 mm 间距后，可排列两个及以上对象。关键对象参照不用于分布。

操作使用对象经旋转、嵌套 SVG、CSS 与镜像变换后的几何外接框；描边、阴影等效果的视觉外扩不计入该框。图文不会被栅格化、展开路径或拆组。每次排版记录为一次撤销，整份工程和可编辑 SVG 保留修改。

原始文字属性仍位于折叠的“文字 SVG 属性”，其余属性保留在“高级 SVG 属性”中。对齐菜单与右侧面板共用同一实现，不另开一套编辑画布。
