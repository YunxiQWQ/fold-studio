# 快速排版工具与功能筛选

本轮参考用户提供的 Illustrator 脚本面板功能目录，挑选适合网页包装工作台的操作，按折间的原生 SVG、双面工程和历史记录独立实现。未运行或复制第三方脚本、字体及素材；原目录中的具体脚本主体为 JSXBIN，功能判断依据为可见面板和按钮目录，不声称完成其内部实现审计。

## 已补入的三类能力

在画布工具栏的 **⋯ → 快速排版** 中使用，不增加独立工具栏。

| 能力 | 在折间中的用法 | 范围与细节 |
| --- | --- | --- |
| 选择相同 | 先选对象，再选“选择同填色”或“选择同类型” | 当前印刷面；跳过隐藏、锁定和 SVG 资源。填色按原始 SVG 样式比较，RGB / CMYK 预览不影响匹配；渐变只匹配相同资源引用，不推断两个渐变看起来是否相同。 |
| 阵列复制 | 输入行、列和横纵净间距；预览数量与总尺寸后创建 | 以当前选区为一组，包含原图共 2–100 组；单位 mm。保留文字、路径、组、裁切和资源引用，条码副本可独立编辑。一次撤销移除整批副本。 |
| 面板定位 | “居中到当前面”保持尺寸；“等比适配当前面”可输入留边 | 多选按整体外接框处理；识别当前面板及内面镜像。适配不改变长宽比，原文字和路径继续可编辑。 |

间距和适配使用图形几何外接框，不包含描边或滤镜扩张。面板适配以外接矩形为准，不执行异形边缘、孔位或生产出血求解。超出元素容量或无效尺寸时拒绝操作，保留原稿。

## 本轮没有重复或迁入的功能

| 面板中的功能 | 决定 |
| --- | --- |
| 包装盒型、纸袋、条码、二维码、分组、图层排序、路径节点、对齐分布 | 折间已有对应能力，保留原入口。 |
| 多页 PDF、Illustrator 画板、链接文件打包、PSD 导出、软件版本设置 | 依赖桌面软件文档环境，不适合直接迁入当前单工程网页。 |
| 印前检查、叠印、专色转印刷色、潘通查询、刀线出血、自动拼版 | 值得单独研究，但需要可说明的生产规则或色库；本轮不把近似效果当成印前合格结论。 |
| 随机颜色、随机透明度、海报/日历/钟表批量生成 | 与当前包装主工作流关系较弱，暂不增加。 |
| 文字查找替换、统一字体、对象尺寸批量编辑 | 后续候选，需要继续处理富文本分段、字体来源和跨组尺寸语义；本轮先完成三类排版工具。 |

所有操作继续在浏览器本地完成，不增加账号、服务器存储或用户信息上传。
