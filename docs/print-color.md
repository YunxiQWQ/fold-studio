# RGB／CMYK 工程模式和印刷导出

顶部按钮或 **印刷设置 → 工程色彩模式** 选择 RGB／CMYK。模式随 `.fold` 和本机工程库保存，支持撤销和重做。旧工程没有该字段时仍可打开。原始图文保留原色，不因切换模式反复改变。

默认印刷配置为 **FOGRA39L Coated**，描述涂布纸胶印条件；可在本机导入印厂的 CMYK 输出 ICC，调整转换意图及黑点补偿。不要把一个通用配置当成所有印机和纸张的共同配置。

## 各导出格式

点击顶部 **导出** 打开统一窗口。左侧预览待导出内容，右侧先选内容，再选格式和色彩模式；按一次底部导出按钮生成文件，不再进入第二层设置弹窗。

- **平面刀版**：当前内面或外面的完整展开图，可选 PNG／JPG／SVG／PDF／TIFF。PNG、JPG、SVG、PDF 可选择是否含刀线与折线；TIFF 固定不含结构线。
- **图文图层**：当前印刷面的可编辑 SVG，不含纸张背景和结构线。
- **三维预览**：当前相机视角的 PNG／JPG。
- **三维模型**：GLB，可选折叠形态、贴图分辨率和是否包含内面图案。

仅显示所选格式适用的选项：JPG 质量、TIFF DPI、PDF 字体与兼容性、GLB 模型设置。TIFF 固定为真实 CMYK；PNG／SVG 的 CMYK 选项明确标注为 RGB 打样显示。导出覆盖色彩模式不会修改工程。切换范围／格式、关闭窗口或预览其他折叠形态也不改动原稿。

左侧预览用于检查内容、结构线和色域；JPG 压缩质量、最终分辨率与 PDF 替代字体不在缩略图中模拟。PDF 字体说明默认折叠，可展开加载字体。小屏幕内容区可滚动，底部文件名、尺寸和操作保持可见。

流程参考成熟工具的内容选择、格式与设置分离：[Illustrator Export for Screens](https://helpx.adobe.com/illustrator/desktop/save-and-export/export-files-to-different-formats/export-artboards-and-assets-for-screens.html)、[Figma 格式设置](https://help.figma.com/hc/en-us/articles/13402894554519-Export-formats-and-settings-for-static-designs)、[Affinity 统一导出与预览](https://affinity.help/designer2/en-US.lproj/pages/ShareSavePrint/export.html)。折间据此采用一个带预览的窗口，避免并列重复入口。

| 格式 | RGB 模式 | CMYK 模式 | 编辑能力 |
| --- | --- | --- | --- |
| 平面／三维 JPG | 标准 RGB 图片 | 真实 8 位 C、M、Y、K 四通道，嵌入 ICC | 合成图片 |
| 刀版／图文 SVG | 原始 RGB 图文 | ICC 打样色域的 RGB 显示值 | 路径、文字、分组继续可编辑 |
| 矢量刀版 PDF | RGB 矢量和图片 | 真实 CMYK 图形、图片和 ICC 输出配置 | 保留路径及嵌入字体，不把整张刀版变成图片 |
| CMYK TIFF | 独立印刷导出项 | 真实四通道和完整 ICC | 合成图片 |
| PNG | 屏幕预览 | ICC 打样后的 RGB 预览 | 合成图片；PNG 不声明 CMYK |

SVG 的常见查看软件使用 RGB 色值；CMYK 模式导出的 SVG 是可编辑的色域显示版，不是承诺任何软件都会按四色打开的文件。需要真实 CMYK 矢量交付时使用 PDF。参考 [W3C SVG 色彩规范](https://www.w3.org/TR/SVG11/color.html)。

**JPG／PDF 导出窗口**默认跟随工程模式，也可以为本次输出另选 RGB 或 CMYK，不改变工程设置。SVG 刀版和当前面图文直接跟随工程模式。JPG／PDF 可选择是否带刀线与折线；三维 JPG 使用当前视角。透明区域在 JPG／TIFF 中铺白，PDF 保留图片透明度。

## 色彩处理

使用 LittleCMS 2.16 WebAssembly 和实际 ICC 数据，不再使用经验式压暗公式。屏幕打样、JPG 转换、PDF 分色和 SVG 显示色使用同一个输出配置。JPG 从 RGB 原稿或未打样的三维截图转换一次，避免二次分色。PDF 对矢量填充、描边、渐变及照片进行 CMYK 转换；照片保持四通道，透明度独立作为灰度软遮罩。

SVG 的路径、文字、分组和剪裁保留；照片只转换图片本身的显示色，不会把矢量部分拍成位图。作为计算数据的遮罩、滤镜等颜色不会被当成普通填色压暗。SVG 的透明混合与渐变插值仍由查看器完成，不等于经过印厂认证的色样。

二维打样缓存最多 2048 像素，跟随同一 SVG 视口，不进入工程。刀版外的待排版素材继续按 RGB 显示。操作图文时临时显示原稿，松开后恢复打样。三维灯光和材质仍会影响外观；屏幕校准、实际印刷配置和纸张影响最终匹配。

## PDF 字体及支持范围

PDF 保留矢量路径和嵌入字体，中文仍可提取。**本版 PDF 的全部文字统一使用所选导出字体**，默认是 OFL 许可的内置中文替代字体，覆盖常用简体字与拉丁字符；这不会修改 SVG 和编辑器的字体。若需要原字形，可加载一个 TTF／OTF／WOFF／WOFF2 字体用于 PDF。字体缺少字符时明确停止，不输出空框。多种原字体的逐一自动匹配尚未提供。

支持常见横排文字、路径、分组、渐变、透明度、剪裁和图片透明度。暂不支持 SVG 滤镜、SVG 遮罩、竖排、非缩放描边、混合模式等效果；出现这些实际内容或转换器报告不能保真的项目时，界面说明原因，不下载残缺 PDF。原 SVG 仍可使用。

PDF 包含真实毫米尺寸与 ICC 输出配置，但**不声明 PDF/X 合规或印厂校样认证**；没有专色、叠印、自动出血、陷印和印厂认证。刀线和折线是可选的普通矢量描边，不是专色版。

## 本机与离线

图片、字体和 ICC 均在本机处理，不上传。用户字体只在导出窗口明确选择文件时读取；不会自动枚举系统字体。引擎、默认 ICC、PDF 引擎和内置中文字体都内联进离线 HTML，离线导出不依赖网络。

ICC 文件最大 4 MB，验证 CMYK 输出类型、长度和标签范围；不适用 RGB 显示器 ICC 或 DeviceLink。TIFF 支持 150／300／600 DPI；上限为 4000 万像素和单边 16000 像素，超限要求降低 DPI，不静默降采样。JPG 平面预览长边 3072 像素，文件记录对应物理 DPI。

## 验证入口

- `npm run test:color`：ICC 参考色、工程、打样、TIFF、旧工程及离线基础流程。
- `npm run test:export-color`：JPEG 四通道／ICC 分段、工程模式、实际 JPG／SVG／PDF 下载、双面、三维、字体错误、明确拒绝不支持内容和手机布局。
- `FOLD_TEST_URL=offline`：运行对应浏览器专项，确认离线零 HTTP 请求。
- 另使用 Pillow／libjpeg、pypdf、Poppler／MuPDF 独立读取、提取文字、检查 CMYK 操作符／ICC／图片通道并渲染核对，不只根据文件名判断色彩模式。
## Illustrator 打开 CMYK PDF 的图片兼容性

CMYK PDF 中的图片以正向四色像素无损嵌入，并保留 ICC 和独立透明蒙版。旧导出方式使用带反转 Decode 数组的 CMYK JPEG，部分 Illustrator 导入流程会忽略反转，从而将图片显示为黑色／负片；标准 PDF 浏览器通常能正常还原。

本轮保留矢量刀线、图形、文字及裁切，不将整张刀版栅格化。JPG 独立导出仍使用原 CMYK JPEG 格式；PDF 中的图片改用 Flate 无损压缩，相同来源图片可复用一个资源。无损压缩的文件大小随内容变化。
