# ICC 印刷色彩与 CMYK 导出

顶部 **印刷设置** 可选择输出 ICC、导入印厂 `.icc` / `.icm`、选择转换意图和黑点补偿，并开启软打样。默认 **FOGRA39L Coated** 为涂布纸胶印条件；其他纸张或设备应使用印厂指定配置。配置随工程保存在本机工程库和 `.fold`，旧工程缺少此字段时使用默认配置。

## 编辑与预览

- 可编辑 SVG 原稿、颜色输入和普通 SVG 导出继续使用 sRGB。浏览器不能把 SVG 变成可通用编辑的原生 CMYK 文档；导出 SVG 时不会把软打样颜色写回原稿。
- 软打样使用 LittleCMS 2.16 WebAssembly 的 ICC proofing transform，目标显示空间为 sRGB，不再使用原来的经验性压暗公式。图文合成后统一转换，覆盖照片、SVG 样式颜色、渐变和透明度，二维、三维纹理和平面 PNG 采用相同引擎。
- 二维软打样为最多 2048 像素的显示缓存，与图文共用同一 SVG 视口，不属于工程图层。包装可印区域外的工作区图文仍按原始 RGB 显示和编辑。拖动或其他按下指针的操作临时显示原始图文，松开后恢复打样；选择、文字和路径仍编辑矢量原稿。这个显示缓存不影响导出分辨率。
- 三维效果仍受场景照明、纸张材质和观察角度影响，不能代替平面色样。软打样及 PNG 仍是屏幕 RGB 图，不是 CMYK 交付文件；显示器校准和实际印刷条件会影响匹配程度。

## 真正 CMYK 文件

**导出 → CMYK 印刷 TIFF** 导出当前内面或外面，选择 150 / 300 / 600 DPI。使用实际毫米尺寸重新渲染，合成透明图文、将剩余透明区域铺白，再通过所选 ICC 转换至 8 位 C、M、Y、K 四通道，并将该 ICC 原样嵌入 TIFF。黑色分色取决于配置文件，不强制所有黑色为单 K。

文件采用 TIFF 6.0 分色模式（PhotometricInterpretation=5、InkSet=1、SamplesPerPixel=4、ICCProfile=34675），单条带、不压缩，包含物理 DPI。可在支持 CMYK TIFF 的印前软件中打开。当前上限为 4000 万像素、单边 16000 像素；超限明确要求降低 DPI，不会悄悄降低分辨率。导出期间保留独立转换句柄，防止其他设置变化污染同一次导出。

TIFF 是合成图，适合图像印刷交付，不保留可编辑文字和矢量。**不包含专色、叠印、矢量 PDF/X、自动出血扩展、陷印或印厂认证校样**。TIFF 默认不输出刀线或折线；结构线另导出可编辑 SVG。需要继续编辑时保存 `.fold` 或 SVG。当前不支持直接输入并保留每个对象的原始 CMYK 通道值。

## 本机与离线

引擎和默认 ICC 内联进构建及离线 HTML，不依赖在线转换服务。用户 ICC 只在明确导入时读取，最大 4 MB，验证文件头、CMYK 输出类型及标签范围；RGB 显示器配置和 DeviceLink 不适用。配置缺少转换表或损坏时显示错误，不替换当前有效设置。

## 验证

`npm run test:color` 运行独立参考色值、像素转换、配置验证、工程兼容和 TIFF 标签单测，再执行浏览器全流程。对照样本来自 Pillow ImageCms / 原生 LittleCMS 2.19，与 WebAssembly 引擎独立运行，覆盖黑白、RGB 三原色及包装常用色。

浏览器测试可用 `FOLD_TEST_URL=offline` 检查离线单文件；可用 `FOLD_TEST_ICC` 指定仅供本机验证的印厂配置。TIFF 输出还通过 Pillow 读取四通道、DPI、ICC 和像素，不把任何用户工程或私有配置放入源码。
