# 常用刀版补充

在“更换结构”中选择“常用彩盒刀版（8 款）”，再在左侧“刀版结构”中切换。新增“手提袋 · 基础刀版”和“天地盖 · 硬盒包边”两张卡片。结构库共 36 张卡片，彩盒卡片内的八种刀版各自保留盖片、插舌、底扣和挂耳的结构差异。

| 用户提供的面板选项 | 折间入口与结构 |
| --- | --- |
| 1.0 / 2.0 直线盒 | 常用彩盒 → 直线盒；圆舌顶盖、反向底盖 |
| 1.0 自锁底盒 / 2.0 锁底盒 | 常用彩盒 → 四片插扣底／自锁底；异形扣片、侧片和圆舌顶盖 |
| 1.0 手提袋 | 手提袋 · 基础刀版；默认无顶部折口、无独立提手，侧风琴折与连续糊底 |
| 1.0 / 2.0 手提盒 | 原有插锁提手盒；双片镂空提手、半幅顶盖、穿槽侧翼和扣底 |
| 1.0 吊挂盒 | 常用彩盒 → 吊挂扣底盒；背面挂片、真实长圆挂孔、四片扣底 |
| 2.0 挂耳盒 | 常用彩盒 → 挂耳粘底盒；正面挂片、真实长圆挂孔、胶合底片 |

| 2.0 上盖盒 | 常用彩盒 → 上盖盒；同向圆舌、不收窄锁肩 |
| 2.0 同向盖 | 常用彩盒 → 同向盖盒；同向圆舌、收窄锁肩 |

“自定 / 其它”没有固定刀版，未当作独立结构增加卡片。手提袋 Pro、极速手提袋、书籍封面等独立工具不属于本轮两个盒型面板的迁入范围。

## 参数与文件

- 彩盒可调盒身长宽高、插舌高度、粘口；两种吊挂结构另可调挂片高度及孔宽高。盒身高不含挂片，界面显示增加的高度。
- 基础手提袋默认 80 × 50 × 60 mm，粘口 12、底折 34、顶部折口 0 mm。可选无提手、绳或缎带，以及原有三种尺寸预设。零折口时不生成退化折面；改用穿孔绳时至少保留 2 mm 折口。
- 硬盒包边天地盖默认底盒 220 × 140 × 30 mm；上盖高、每侧套合间隙与包边可调。上盖长宽为底盒加两倍间隙；包边按各片壁高限制。此结构表示包纸，不额外生成灰板切割图。
- 所有新增结构沿用双面 SVG 编辑、`.fold` 工程、可编辑 SVG、平面 PNG、三维 GLB 和离线 HTML。格式版本与旧工程读取路径保持原样；新增结构需要本版或更新版本才能打开。

## 实现边界

这些参数化模型根据本机 Illustrator 临时文档中实际生成的展开结构独立实现。未将第三方 JSX / JSXBIN、导出的参考图、字体或品牌素材放入源码、构建及开源附件。原始临时核对材料保留在 Git 忽略的 `artifacts/dieline-review/`。

本轮迁入结构能力，没有逐点复刻原脚本的纸厚补偿、缩位及生产经验值。插扣、糊底和套合采用折叠几何预览，不执行纸张受力、胶合或接触求解；实际制样仍需按材料与工艺校核。
