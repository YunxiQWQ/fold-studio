# Bundled CMYK ICC

`FOGRA39L_coated.icc`: **FOGRA39L Coated**, 121,368 bytes.

- SHA-256: `b35713ef7eff09349d4c3249e5f377736d06d8a2671c54712971a3546bf17c57`.
- Original binary: https://github.com/norbusan/colorprofiles/blob/master/FOGRA39L_coated.icc
- Colord source definition / characterization data: https://github.com/hughsie/colord/blob/main/data/profiles/FOGRA39L_coated.iccprofile.xml
- The source definition and binary `meta` tag declare **CC0**; the binary copyright tag says: “This profile is free of known copyright restrictions”. No profile data was modified.
- Describes coated/matte paper types 1 and 2, sheetfed offset, FOGRA39L. It is a generic printing condition, not a profile for every printer or stock, and is not the ECI `ISOcoated_v2_eci.icc` profile. Separation and total ink coverage come from this exact profile; no additional ink-limit policy is imposed.

The UI permits a user-supplied CMYK output ICC. Custom profiles remain in the user's local project / downloaded `.fold` backup; the app does not upload or publish them. No ECI profile is bundled.
