# 折间 Fold Studio

一个以流畅编辑为优先的本地网页包装工作台。参考 [OpenBox3D](https://github.com/yuyou-dev/OpenBox3D) 的“参数化刀版 → 平面设计 → 三维折叠”工作流，重新实现轻量渲染与交互。原项目仅作设计和技术研究参考，未复制其应用源码、预设或素材。

**在线体验：** [tool.heyunxi.top/fold](https://tool.heyunxi.top/fold)  
**开源许可：** MIT，作者署名为 Yun-xi 与 OpenAI Codex。第三方代码和图标的许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 开发与部署

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run build
npm run dev
```

Vercel 从仓库根目录构建，输出目录为 `dist`。仓库内的 `vercel.json` 将 `/fold` 映射到应用入口，并保留其静态资源路径。

## 直接使用

**最简单：双击 `折间.html`，用 Edge 或 Chrome 打开。**这是已打包的离线单文件，无需安装、联网或启动服务器，包含全部运行代码。已验证通过 `file://` 打开后的三维预览、文字编辑与草稿恢复，未请求外部网络。

也可以双击 **启动折间.cmd**，通过本机 HTTP 地址使用。同一浏览器中，HTML 文件版和 HTTP 版的草稿分开保存，可通过 `.fold` 工程互相传递。当前电脑已核实有 Node.js；在其他电脑使用 HTTP 启动器需要 Node.js 22 或更新版本。

也可以在本目录执行：

```powershell
node server.mjs --open
```

HTTP 版无需安装依赖即可运行已经构建的 `dist/`。关闭启动窗口或按 Ctrl+C 停止。默认地址 `http://127.0.0.1:4186`，端口占用时依次尝试后续端口；以终端实际显示为准。固定地址与端口有助于找到同一份浏览器草稿。

## 内外面与跨页面复制

1. 点击画布上方“外面 / 内面”，再选择需要编辑的面板；添加的图文归属于当前面，颜色和图层互相独立。
2. 右侧图层属性中的“印刷面”可以把现有图层移动到另一面，也可以通过复制粘贴保留原图层。
3. 盒子折合时内面可能被遮挡。点击 3D 区域的“展开查看当前面”，会展开结构并转到正确的阅读方向。
4. 选中图层，在画布或图层列表中按 `Ctrl+C`。切换另一个折间标签页、离线页面或工程，选择目标面板和内外面，再按 `Ctrl+V`。文字格式、图片数据、旋转和实际宽高会一并携带；位置沿用相对位置并略微偏移，`Ctrl+Shift+V` 保留原相对位置。
5. 可从其他网页或软件粘贴普通文字、PNG/JPG/WebP 图片；外部编辑软件的复杂图层结构不会自动转换为本应用的可编辑图层。

输入框内的文字复制粘贴保持浏览器原生行为。按钮读取剪贴板受浏览器权限限制时，可直接按 Ctrl / ⌘ V；原生快捷键在不授予 Clipboard API 权限的两个离线页面之间也已验证。跨页面使用系统剪贴板，不依赖当前页面的内存副本。

导出平面 PNG / SVG 时使用当前编辑面；内面导出与背面视图方向一致。`.fold` 工程与 SVG 中的工程元数据都包含内外两面。旧版单面工程可直接打开，原图层自动归为外面；新工程采用版本 2 数据结构，旧版 0.1 应用不能读取，请使用新版应用打开。

## 性能设计

- **按需绘制**：静止时不运行常驻渲染循环，页面隐藏时停止动画。
- **更新分离**：折叠只更新面片矩阵，镜头只更新视角；二者不重建几何或烘焙图文。
- **每面一张颜色图集**：三个预览档位最长边约 768 / 1536 / 2048 px；图片导入时缩到最长边 1536 px。仅更新发生变化的一面，图集不携带昂贵的工艺贴图。
- **限制屏幕像素密度**：均衡档 DPR 上限 1.35；两盏方向光，无阴影贴图、HDRI、后处理或位移贴图。
- **释放旧资源**：结构变化时回收旧几何，图集尺寸变化时释放并替换 GPU 纹理。
- **独立平面视口**：Canvas 2D 绘制刀版与选择框，缩放和平移不会触发 3D 贴图上传。

对 OpenBox3D 的源码观察：其 `src/render3d/engine.js` 包含常驻 requestAnimationFrame 渲染、最高 DPR 2、多采样阴影；`bake.js` 图集上限为 4096，使用多个 PBR 通道。这些是本版本减少的工作负担，**不是对原项目卡顿根因的完整性能诊断**。没有在相同设备和场景下完成两项目速度对比，不承诺固定帧率或提升倍数。

## 当前边界

- 支持十二款预设参数化盒型与瓶罐容器。**任意外部 SVG/PDF/DXF 刀版自动识别、手动折叠关系标注、刀线节点编辑尚未实现**。打开 SVG 仅支持本应用导出且包含工程信息的文件。
- 图文可跨整张刀版连续排版，也可选为仅基准面板裁切；仍限于当前印刷面，不会自动绕过裁切边或转到纸张背面。
- 固定 0.45 mm 厚度用于显示，插舌与重叠部位采用微层间距避免 Z-fighting，不包含工业级实际纸厚补偿、模切制造公差或刀版反弹力学仿真。
- 刀版尺寸以几何面片为基准；不能直接当作已验证的生产文件。不含 CMYK、专色、出血、安全区、烫金或 UV 分版。
- 图文字体使用系统可用字体，跨电脑可能变化；SVG 图文位图可保留当次导出外观。
- 草稿绑定当前浏览器与本机地址，文件版草稿的隔离规则也取决于浏览器；重要设计请下载 `.fold` 备份。最多 120 个图层，40 步历史。默认只是内存示例，首次编辑后写入草稿。
- 完全本地运行，不需要账号、后端、外部字体或云端图片服务。HTTP 服务器只绑定 127.0.0.1 并提供静态资源。

```powershell
npm install

```

构建需要 Node.js 22.12+。当前锁定 Node 实测 22.23.3、Vite 8.3.4、Three.js 0.186.1、Playwright 1.64.1。

浏览器测试优先使用本机已安装的 Playwright Chromium（当前 Windows 默认检查缓存中的 chromium-1228），也可以设置 `FOLD_BROWSER_PATH` 指向自己的 Chromium；未安装时可运行 `npx playwright install chromium`。测试使用软件 WebGL，验证行为和资源更新，不代表用户显卡的实际交互帧率。
